PROJECT NAME: COMMUNITY OF COURSSIN DEVELOPERS (CCD)

TAGLINE: BUILD • LEARN • INNOVATE • GROW

==================================================
1. PROJECT OVERVIEW
==================================================

Build a professional, modern, creative, responsive and fully functional website for Community of Courssin Developers (CCD).

CCD is a technology community designed to bring together beginner developers, intermediate developers and experienced technology professionals.

The community exists to encourage continuous learning, practical development, teamwork, networking, innovation and professional growth.

The goal is to eliminate the isolation that often occurs when developers learn independently without interacting with other professionals.

CCD will provide an environment where members can:
- Learn from one another.
- Participate in development challenges.
- Work on collaborative projects.
- Receive assigned technical tasks.
- Share knowledge and resources.
- Develop teamwork and leadership skills.
- Participate in technology events.
- Earn recognition and rewards.
- Build professional relationships.

This must not look like an ordinary blog or basic membership website.

It should look and function like a premium technology community platform.

5. TWO-BATCH MEMBERSHIP SYSTEM
==================================================

CCD admits members twice every year.

Each membership batch lasts six months.

BATCH A:
January - June.

BATCH B:
July - December.

Each batch operates independently but belongs to the same community.

Example:

2027 MEMBERSHIP CALENDAR:

January - June 2027:
Batch A.

July - December 2027:
Batch B.

The system must support different years and configurable registration periods.

Each batch must have:

- Batch name.
- Batch year.
- Start date.
- End date.
- Registration opening date.
- Registration closing date.
- WhatsApp group invitation.
- Membership capacity (optional).
- Batch description.
- Batch status.

BATCH STATUSES:

- Upcoming.
- Registration Open.
- Registration Closed.
- Active.
- Closing Soon.
- Completed.
- Archived.

Administrators should be able to open and close registration manually.

The system should automatically identify the active batch based on configured dates.

6. MEMBERSHIP REGISTRATION
==================================================

Implement a two-stage registration process.

STAGE ONE: ACCOUNT CREATION

Visitors should be able to create an account using:

- Full name.
- Email address.
- Password.
- Confirm password.

Use Supabase Authentication.

Require email verification before allowing membership registration.

STAGE TWO: COMMUNITY MEMBERSHIP REGISTRATION

After logging in, users should access a membership registration form.

PERSONAL INFORMATION:

- Full name.
- Email address.
- Phone number.
- Country.
- City.
- Profile picture (optional).

DEVELOPMENT INFORMATION:

- Preferred development category.
- Current skill level.
- Technologies and tools currently used.
- Areas of interest.
- GitHub profile (optional).
- Portfolio website (optional).
- LinkedIn profile (optional).

ADDITIONAL INFORMATION:

- Why do you want to join CCD?
- Do you have previous teamwork experience?
- Are you available for group projects and activities?

BATCH SELECTION:

Display available batches.

Example:

Batch A - January to June 2027.
Batch B - July to December 2027.

Only display batches whose registration status is OPEN.

Allow the applicant to select their preferred batch.

Include acceptance of community rules and terms.

REGISTRATION SUBMISSION:

When the user clicks SUBMIT:

1. Validate all required information.
2. Verify the authenticated user.
3. Check whether the selected batch is open.
4. Check for duplicate registration.
5. Save the membership application in Supabase.
6. Retrieve the correct batch information.
7. Retrieve the corresponding WhatsApp group invitation securely.
8. Trigger a Supabase Edge Function.
9. Send a confirmation email through Resend.
10. Display a successful registration message.

Prevent duplicate registrations into the same batch.

10. CCD TRANSITION AND DELEGATION PROGRAMME
==================================================

Create a dedicated system for outgoing batch members.

At the end of every six-month membership cycle, selected members of the outgoing batch should participate in organising the next Tech Cohort.

This programme should be called:

CCD TRANSITION & DELEGATION PROGRAMME.

Administrators should be able to select outgoing members for:

- Tech Cohort Organisers.
- Delegates.
- Technical Organisers.
- Event Coordinators.
- Publicity Organisers.
- Registration Coordinators.
- Other organising positions.

TRANSITION PROCESS:

STAGE 1:
Outgoing members complete their assignments and projects.

STAGE 2:
Administrators select outstanding and committed members.

STAGE 3:
Selected members receive organising appointments.

STAGE 4:
The organising committee plans the next Tech Cohort.

STAGE 5:
The Tech Cohort takes place.

STAGE 6:
The outgoing committee documents its activities and completes the handover.

Maintain historical records of appointments and committee activities.
